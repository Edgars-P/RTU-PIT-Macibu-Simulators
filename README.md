# Mācību simulators

<img width="1724" height="1018" alt="Screenshot 2026-11-11 at 23-05-58 Mācību simulators" src="https://github.com/user-attachments/assets/05255b07-1c6a-4596-8980-c21419306569" />

Sistēmas mērķis ir palīdzēt studentiem automatizēt mācīšanās un zināšanas kontroles procesu.
Students sistēmā ievada vai augšupielādē savus studiju materiālus, tad Integrētais MI modelis
veic dokumentu analīzi un ģenerē personalizētu pārbaudījuma simulāciju kursa stilā. Pēc tam,
balstoties uz studenta atbildēm, sistēma dod atgriezenisko saiti tālākai izpratnei. Administratori
atbild par sistēmas lietotāju pārvaldību, sistēmas iestatījumiem un MI moduļa darbību.
